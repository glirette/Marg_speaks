# Public source review — September 14, 2026

The Jaren Lockhart case is the first case file prepared for New Orleans Crime.
This review adds a modern reading layer around the original Marg Speaks artifact.
The original HTML and tracked supporting files are unchanged.

## Public outcomes and citations

- The [Louisiana Fifth Circuit opinion in 16-KA-163](https://cases.justia.com/louisiana/fifth-circuit-court-of-appeal/2016-16-ka-163.pdf?ts=1481137709) affirms Speaks’s convictions and sentences on December 7, 2016. Printed pp. 34–36 distinguish the initial sentences from the later enhancement of the obstruction count.
- The [Jefferson Parish District Attorney’s June 20, 2016 account](https://www.jpda.us/metairie-woman-pleads-guilty-to-death-dismemberment-of-jaren-lockhart/) names Sanchez’s plea offenses and describes concurrent sentences. This replaces reliance on a news description for those particulars in the modern case file.
- [WXXV’s October 17, 2017 report](https://www.wxxv25.com/no-appeal-new-orleans-murderer/) describes a later Louisiana Supreme Court refusal to review Speaks’s case. The publication date is not treated as the independently established order date.

The public case data includes source IDs, event dates, review dates, and source
limits. The generated timeline and source index use that same data.

## Verification limits

This review did not obtain a current custody record, the Supreme Court action
sheet, certified Sanchez plea minutes, or a complete later state/federal docket.
It does not establish present custody, release eligibility, or the absence of
later proceedings. Current-source review means the listed sources were reviewed
on this date; it does not mean their historical events happened in 2026.
