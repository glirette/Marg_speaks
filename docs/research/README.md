# Public research: the Jaren Lockhart case

This directory and this repository are the public research home for **this case**.
The broader New Orleans Crime publication consumes reviewed material from here;
research about other cases belongs elsewhere.

Start with the [September 14, 2026 source review](2026-09-14-source-review.md),
which records source support, access limits, and the open verification queue.
The [September 26 later-record check](2026-09-26-later-record-check.md) records
additional court and custody lookup limits, a separate case-number lead, and
the unresolved identity matches. It depends on the still-unmerged case file in PR #5.

- [Open issues](https://github.com/glirette/Marg_speaks/issues)
- [Public pull requests](https://github.com/glirette/Marg_speaks/pulls)
- [Contribution standards](../../CONTRIBUTING.md)
- [Publication contract](../publication-contract.md)

Research can be incomplete and still be public. Label what was actually observed,
what is attributed to reporting, and what remains unresolved. Do not turn a lead
or an inaccessible source into a finding. Corrections should preserve the source
and date that justify them.
